
# 2D Rocket Launch Simulator

A simple 2D Rocket Launch Simulator developed using Python and OpenGL.

## Features

- 2D Rocket Design
- Rocket Launch Animation
- Animated Rocket Flame
- Left and Right Movement
- Rocket Reset Option
- Simple Graphical Environment

## Controls

| Key | Action |
|---|---|
| UP Arrow | Launch Rocket |
| LEFT Arrow | Move Left |
| RIGHT Arrow | Move Right |
| DOWN Arrow | Reset Rocket |

## Technologies Used

- Python
- PyOpenGL
- PyOpenGL_accelerate
- GLUT

## Installation

Install the required libraries:

```bash
pip install PyOpenGL PyOpenGL_accelerate
```

On Ubuntu, install GLUT:

```bash
sudo apt install freeglut3-dev
```

## Run the Project

```bash
export PYOPENGL_PLATFORM=glx
python rocket.py
```
